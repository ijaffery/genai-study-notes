# Build a GPT from Scratch

*Build a character-level or word-level transformer language model end-to-end: tokenization, embedding, attention, MLP, training loop, generation.*

## Topics to cover

- Tokenization (BPE, byte-level)
- Embedding layers
- Transformer block architecture
- Training loop with loss/backward
- Text generation (greedy, sampling, top-k, top-p)
- Evaluation metrics (perplexity)
